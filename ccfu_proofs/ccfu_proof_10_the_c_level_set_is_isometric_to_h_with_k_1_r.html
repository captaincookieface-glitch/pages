CCFU Proof 10 — The C₂ Level Set Is Isometric to H³ with K = −1/R²

text
Given.
G₄ is the invariant quadratic form with sig(G₄) = (3,1)  [Proof 4].
A₄ᵀG₄A₄ = G₄  [Proof 4].
Q(v) = vᵀG₄v.
Let R > 0. Define M_R = {v ∈ R⁴ : Q(v) = −R²}.

Part A — Explicit isometry M_R⁺ ≅ H³.

By Sylvester's law of inertia, since sig(G₄) = (3,1),
there exists an invertible matrix P such that:

    PᵀG₄P = η,  η = diag(−1,+1,+1,+1).

Set f(v) = P⁻¹v and w = f(v).

(i)  f is linear and bijective (det(P) ≠ 0).
(ii) Q(v) = vᵀG₄v = wᵀηw.
(iii) Q(v) = −R² iff wᵀηw = −R², i.e.,
     −w₀² + w₁² + w₂² + w₃² = −R².

This is the standard two-sheeted hyperboloid.
Choose the sheet w₀ > 0 and call it M_R⁺.
This is the standard hyperboloid model of H³(R).

Therefore f restricts to an isometry from (M_R⁺, G₄) to (H³(R), η).  ∎

Part B — Induced metric.

Parametrize H³(R):

    w₀ = R·cosh(r)
    w₁ = R·sinh(r)·sin(θ₁)·cos(θ₂)
    w₂ = R·sinh(r)·sin(θ₁)·sin(θ₂)
    w₃ = R·sinh(r)·cos(θ₁)

Direct computation gives the induced metric:

    ds² = R²(dr² + sinh²(r)(dθ₁² + sin²(θ₁)dθ₂²))

This is the standard global H³ metric with scale R.  ∎

Part C — Sectional curvature.

The unit normal to M_R⁺ in the standard coordinates w = f(v) is n = w/R,
which is timelike: η(n,n) = −1.
The shape operator is S = −(1/R)I.
For any orthonormal tangent 2-plane, the Gauss equation in flat
ambient space gives:

    K = η(n,n) · (1/R²) = (−1) · (1/R²) = −1/R²  ∎

Conclusion.
For each R > 0, each connected sheet of M_R = {v : Q(v) = −R²}
is linearly isometric to H³(R), the hyperbolic 3-space of constant
sectional curvature K = −1/R². The result depends only on the
C₂-derived signature sig(G₄) = (3,1). No additional parameters
are chosen beyond R.
