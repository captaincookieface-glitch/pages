CCFU Proof 5 — The Minimal Parent Theorem: dim(P_min) = 5 = Δ(C₂)

text
Definition.
A signed parent P is a finite-dimensional real vector space
with a nondegenerate symmetric bilinear form of signature (p,q),
containing nondegenerate subspaces of signatures sig(3,1) and sig(2,2).

Dependencies.
sig(3,1) from Proof 4 [C₂ linear closure]
sig(2,2) from Proof 3 [C₂ nonlinear memory, at fixed point; strengthened globally in Proof 16]

Part A — Δ(C₂) = 5.

C₂ characteristic equation: λ² − λ − 1 = 0
Δ = (−1)² − 4(1)(−1) = 1 + 4 = 5  ∎

Part B — Lower bound (dim ≥ 5).

To contain sig(3,1): need p ≥ 3, q ≥ 1.
To contain sig(2,2): need p ≥ 2, q ≥ 2.
Together: p ≥ max(3,2) = 3, q ≥ max(1,2) = 2.
dim = p + q ≥ 5  ∎

Part C — Upper bound (dim ≤ 5).

Take R⁵ with Q(a,b,c,d,e) = a² + b² + c² − d² − e²
sig(Q) = (3,2)

Subspace e=0: Q = a²+b²+c²−d², sig = (3,1) ✓
Subspace c=0: Q = a²+b²−d²−e², sig = (2,2) ✓

Therefore dim ≤ 5.  ∎

Part D — Uniqueness.

In dim 5, possible signatures: (5,0), (4,1), (3,2), (2,3), (1,4), (0,5)

(4,1): q=1 < 2, cannot contain sig(2,2).
(2,3): p=2 < 3, cannot contain sig(3,1).
(5,0),(0,5): definite, cannot contain mixed signature.
(1,4): p=1 < 3.

Only (3,2) works.  ∎

Conclusion.
Δ(C₂) = 5.  dim(P_min) = 5.  sig(P_min) = (3,2).
P_min has signature sig(3,2). Its dimension equals the discriminant of C₂. No parameters are chosen.  ∎
